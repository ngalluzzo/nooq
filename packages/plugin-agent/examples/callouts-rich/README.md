A text callout with an info, warning, or success tone. Preserve text, marks, unknown fields, and children. Diagnose invalid or missing tone without changing content. The cycle command applies only to live blocks of this exact type with a valid tone; invalid stored tone declines the action. Extra command arguments are harmless. Commands return ordinary setField operations and a nonempty intent. Use defineBlockSchema, field.enum, cycleFieldCommand and insertBlockCommand to avoid duplicating standard validation and operations. The view must use mountRichText. RichFormatting exercises bold formatting with keyboard interaction and verifies the visible formatted text.
