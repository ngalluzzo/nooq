# Callout

A text callout with an info, warning, or success tone. Preserve text, marks, unknown fields, and children. Diagnose invalid or missing tone without changing content. The cycle command applies only to live blocks of this exact type with a valid tone; invalid stored tone declines the action. Extra command arguments are harmless. Commands return ordinary setField operations and a nonempty intent.

Generated candidate for the nooq plugin API. Review src/index.ts and report.json before copying into the nooq workspace. This package uses workspace dependencies and is not a standalone published package.

Open preview.html for the isolated working preview when browser checks ran; report.html is the static validation summary. src/plugin.stories.ts contains standard CSF3 stories with interaction tests and can be included in the host Storybook stories glob. There is no automatic installation, merge, or publication. The report names the supported checks and remaining integration gaps.
