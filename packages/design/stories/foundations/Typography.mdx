# Typography

Three faces, each with one job. Literata sets the document, because the writing surface is what nooq is designed around. Atkinson Hyperlegible Next sets the chrome; it keeps I, l and 1 apart for low-vision readers (§9). Atkinson Hyperlegible Mono sets anything a machine wrote and a person compares. All three are self-hosted through `@nooq/design/fonts.css`, so type survives airplane mode (§2).

Each style is a class: `.nq-<name>`.
