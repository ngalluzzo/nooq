# Color

Color in nooq means an actor. The document is graphite on paper; hue only appears where something says who did what. Each swatch shows the light and dark value of `--nq-<name>`. Edit `tokens.json`, then run `bun run tokens`.

      subtitle={t.usage}
      colors={{ Light: resolveColor(tokens, t.name, "light"), Dark: resolveColor(tokens, t.name, "dark") }}
    />
  ))}
</ColorPalette>

## Contrast, enforced

Every pair below is a promise made in a usage note, and `test/contrast.test.ts` fails the build if any drops under its minimum: 4.5:1 for text, 3:1 for control borders and marks that carry meaning.

export const pairs = (() => {
  const results = checkContrast(tokens);
  const light = results.filter((r) => r.theme === "light");
  return light.map((r) => ({ ...r, dark: results.find((d) => d.theme === "dark" && d.fg === r.fg && d.bg === r.bg && d.min === r.min) }));
})();
